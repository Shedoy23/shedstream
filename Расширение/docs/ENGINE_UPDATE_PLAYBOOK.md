# ENGINE_UPDATE_PLAYBOOK — что делать при выходе нового патча Bannerlord

ROADMAP 2.7. Цель: следующий патч Mount & Blade II Bannerlord **не должен** повторить
инцидент 1.4.5 (Steam молча автообновил игру → моды стали несовместимы → сейв/стрим
сломались). Это пошаговый чеклист на момент, когда Steam показывает обновление игры.

> Контекст: наш мод `BannerlordLink` собирается против game-DLL по
> `X:\SteamLibrary\...\Mount & Blade II Bannerlord\bin|Modules\SandBox|Native`
> (см. `.csproj` / `BANNERLORD_DEV_ENV.md`). Обновился движок → DLL изменились → **мод надо
> пересобрать**, а сторонние зависимости — обновить до версий под новый движок. Если этого
> не сделать (или сделать раньше, чем вышли совместимые моды) — крэш на старте или порча сейва.

---

## 🥇 Золотое правило
**Не обновляй игру сразу.** Движок почти всегда выходит РАНЬШЕ, чем под него обновляются
моды (Harmony, ButterLib, UIExtenderEx, MBOptionScreen + геймплейные Diplomacy и т.д.).
Обновиться в этот зазор = гарантированно сломать моды. **Ждём, пока зависимости догонят.**

---

## Шаг 0 — превентивно (настроить ОДИН раз, прямо сейчас)
Чтобы Steam не обновил игру сам в неудобный момент (как в 1.4.5):
- Steam → ПКМ на **Mount & Blade II Bannerlord** → **Свойства → Обновления** →
  «Автообновление» поставить **«Обновлять только при запуске игры»** (не «Всегда»).
- Перед стримом игру запускать **только после** того, как прошёл этот плейбук — иначе
  запуск сам потянет обновление.
- (Опц.) если ловишь нестабильность — на время можно запретить выход в онлайн Steam
  перед запуском, чтобы точно не дёрнул апдейт.

---

## Шаг 1 — патч вышел: НЕ обновляйся, подготовься
1. **Бэкап ВСЕГО рабочего состояния (пока всё ещё работает):**
   - сейв(ы): `…\Mount and Blade II Bannerlord\Game Saves\…` → копию в надёжное место;
   - текущий **рабочий DLL** мода (`Modules/Shedoy23.BannerlordLink/bin/Win64_Shipping_Client/BannerlordLink.dll`);
   - список и версии **текущих сторонних модов** (скрин папки `Modules/` или launcher'а).
2. **Дождись совместимости зависимостей.** Проверь страницы (Nexus/Steam Workshop) ключевых:
   Harmony, ButterLib, UIExtenderEx, MBOptionScreen + геймплейные (Diplomacy, SmartRecruit,
   AutoEquipCompanions и пр. из твоего сборки). Пока ХОТЯ БЫ ОДНА из них не вышла под новый
   движок — **не обновляйся**, играй на старой версии.
3. Отметь новую версию игры в `BANNERLORD_COMPAT_MATRIX.md` (что с чем совместимо).

---

## Шаг 2 — зависимости готовы: обновляемся
1. **Ещё раз бэкап** сейва + текущего DLL (страховка перед изменением).
2. Дай Steam **обновить игру**.
3. Обнови **сторонние моды** до версий под новый движок.
4. **Пересобери наш мод против новых DLL:** `pwsh scripts/deploy.ps1 -Mod`
   (он берёт game-DLL из `X:\SteamLibrary\...`, собирает + кладёт в игру + md5-verify).
   Если сборка ругается на изменившийся API TaleWorlds — чинить точечно (см.
   `BANNERLORD_API_CHEATSHEET.md`), это норма при крупных патчах.
5. Обнови `BANNERLORD_COMPAT_MATRIX.md`: версия игры × версии модов × «ОК/сломано».

---

## Шаг 3 — тест на STAGING-сейве ПЕРЕД стримом (не на основном!)
1. Сделай **копию** сейва — тестируй на ней, не на основной/стримовой.
2. Запусти игру, проверь:
   - игра **не крэшит на старте**, мод грузится (в мод-логе строки `[BannerlordLink]` init,
     `finalizer registered` от патчей);
   - смоук-тест по `TESTING_PLAYBOOK.md` (зайти в бой, купить действие из расширения,
     проверить что перки/награды приходят).
3. Всё зелёное → можно на основной сейв / в стрим. Что-то крэшит → **на стрим НЕ идём**,
   чинить (или откат, см. ниже).

---

## 🔙 Если сломалось — откат
- **Сейв:** восстанови из бэкапа (см. `RESTORE_PLAYBOOK.md`).
- **Версия игры:** Steam штатно откат не даёт. Варианты: бета-ветка прошлой версии в
  свойствах игры (если у патча есть `previous`-branch), либо DepotDownloader для пина
  конкретного билда. Поэтому **главная защита — не обновляться, пока не готов, + бэкапы**.
- **DLL мода:** верни сохранённый рабочий `BannerlordLink.dll` из Шага 1.

---

## Связанные доки
- `BANNERLORD_DEV_ENV.md` — окружение сборки мода (пути, DLL, dotnet).
- `BANNERLORD_COMPAT_MATRIX.md` — матрица «версия игры × моды».
- `BANNERLORD_API_CHEATSHEET.md` — если патч поменял TaleWorlds API при пересборке.
- `TESTING_PLAYBOOK.md` — смоук-тест в игре.
- `RESTORE_PLAYBOOK.md` — восстановление сейва/данных.

**Одной строкой:** патч вышел → НЕ обновляйся → бэкап → жди совместимых модов → обновись +
пересобери `deploy.ps1 -Mod` → тест на КОПИИ сейва → только потом в стрим.
