# Manager → Bannerlord: живой install 2026-08-19

## Исход

ShedLink Manager впервые вживую установил и настроил BannerlordLink без ручной
правки JSON, копирования DLL или передачи token/API URL.

## Красный сценарий

`alpha.4` скачивал и проверял релиз, но откатывал установку с сообщением об
отказе Windows в записи. Добавленный безопасный журнал показал точную причину:
`ManagedConfiguration.RestrictToCurrentUser` вызывал `FileSecurity.SetOwner`.
Новый файл уже принадлежал текущему пользователю, а повторное назначение
владельца требовало административной привилегии на этой Steam library.

## Исправление

Лишний `SetOwner` удалён. Manager по-прежнему отключает наследование ACL и
оставляет полный доступ только SID текущего Windows-пользователя. Запуск от
администратора не требуется.

## Зелёное доказательство

- установка обычным пользователем завершилась успешно;
- установлена версия BannerlordLink `0.1.0`;
- в папке мода только три release-файла и созданный `config.json`;
- backend URL, channel ID и module token заполнены автоматически;
- значение token в отчёт не выводилось;
- `config.json` принадлежит текущему пользователю, наследование ACL отключено;
- stage/backup/transaction-файлов после успеха нет;
- Manager state хранит Bannerlord game root и release `0.1.0`;
- Core self-test и Release build после исправления: код `0`.

Следующая живая граница — запустить Bannerlord, получить heartbeat и завершить
`Проверить готовность` до `Technical Ready`.
