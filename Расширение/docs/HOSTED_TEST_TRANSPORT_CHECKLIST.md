# Hosted Test — короткий ручной чек-лист транспорта

Дополняет `REVIEWER_WALKTHROUGH.md`, а не заменяет его: там проверяется, что
расширение делает то, что обещает ревьюеру. Здесь — что оно **не теряет и не
повторяет** данные, то есть ровно то, что нельзя доказать чтением кода.

Пройти ОДИН раз на том архиве, который лежит в кабинете. Не на локальном тесте.

**Архив на момент написания:** `0.0.5`, SHA-256 `513ff646…`,
MD5 `34bad42f0c6a7f0130e84a4f20e3a41e`, 247 938 байт, cache-bust `202609090834`.
Актуальные значения — всегда в `RELEASE_RECORD.md`, первая запись.

Заполнять прямо здесь: дата и результат словами, а не галочкой.

---

## 0. Сверка того, что проверяем

| Проверка | Как | Результат |
|---|---|---|
| MD5 загруженного ZIP совпадает с локальным | В Dev Console у версии → сравнить с `RELEASE_RECORD.md` | |
| Открыт именно Hosted Test | В консоли статус версии = «Тест на сервере» | |
| Панель грузится с CDN-домена | DevTools → Network → домен `…ext-twitch.tv`, не локальный | |

**Если MD5 не совпал — дальше не идти.** Всё остальное будет проверкой другого
пакета; так уже было 09.09, когда в кабинете лежал архив на два шага позади.

## 1. Вход

| Сценарий | Ожидаемо | Результат |
|---|---|---|
| Desktop: открыть панель на своём канале | Ник и баланс появились, «Загрузка…» не висит | |
| Desktop: отозвать доступ и войти заново | Карточка входа появляется, после согласия панель оживает | |
| **iPhone**: открыть панель | Ник и баланс появились | |
| iPhone: свернуть приложение на минуту и вернуться | Баланс на месте, карточки входа НЕТ | |

iPhone обязателен: мобильная оболочка — отдельный файл, и исходный сбой
07.09–08.09 наблюдался именно там. Причина того сбоя доказанной не считается.

## 2. Потеря и восстановление сети

| Сценарий | Ожидаемо | Результат |
|---|---|---|
| Выключить Wi-Fi на 30–60 с при открытой панели | Тост про недоступность сервера; баланс НЕ обнуляется в 0 | |
| Вернуть сеть, подождать минуту | Баланс/доход/квесты вернулись сами, без перезагрузки страницы | |
| DevTools → Console | Нет CSP, mixed-content, 404 и uncaught | |

Ключевое отличие: «данные неизвестны» показывается прочерком «—», а НЕ нулём.
Ноль означает «у тебя правда ноль».

## 3. Обновление игрового состояния (зеркало)

Требует запущенной игры. Проверяет правку 09.09 — снимок считается
доставленным только после подтверждения, отправки идут по одной.

| Сценарий | Ожидаемо | Результат |
|---|---|---|
| Изменить золото героя в игре, подождать ~40 с | В панели новое золото | |
| Отключить сеть на игровом ПК на минуту, вернуть | В `Player.log` есть `снимок НЕ подтверждён — повторим на следующем тике`, и в течение минуты зеркало догоняет само | |
| Загрузить ДРУГОЙ сейв | Панель показывает состояние нового сейва, не прошлого | |

До правки после любой сетевой ошибки зеркало замерзало навсегда — это и есть
то, что здесь проверяется. Строка `подтверждение устарело (сменился сейв)` в
логе — нормальна.

## 4. По одному полному платному действию на каждую живую игру

Для каждого: нажать → дождаться исхода → проверить баланс и текст.

| Игра | Действие | Что смотреть | Результат |
|---|---|---|---|
| Bannerlord | найм свиты | списались **динары** (не крустики); свита выросла на столько, за сколько заплачено | |
| Bannerlord | покупка мастерской | списались **2 500 крустиков**; мастерская появилась | |
| RimWorld | создание пешки | списались **200 крустиков**; пешка появилась в игре | |
| ShedColony | любое из панели | списались крустики; эффект виден в игре | |

**Отдельно — отказ.** Нажать действие, заведомо невозможное (например,
требующее клана, когда клана нет). Ожидаемо: крустики вернулись **ровно** те же
и пришло текстовое объяснение, а не молчание.

**Отдельно — двойной клик.** Быстро нажать одно действие дважды. Ожидаемо: один
эффект и одно списание, второе нажатие не создаёт вторую покупку.

## 5. Что этот чек-лист НЕ проверяет

Честно, чтобы не создавать ложного спокойствия:

* **Падение процесса ровно между игровым эффектом и записью журнала исходов.**
  И Bannerlord, и ShedColony пишут журнал после применения эффекта; смерть
  процесса между ними даёт повторное применение при повторной доставке.
  Exactly-once здесь не достигнут и не обещается.
* **Откат к более старому сейву.** Действия, уже записанные выполненными,
  останутся такими и после отката.
* Поведение при нескольких одновременных зрителях — на одном канале не
  воспроизводится.
