## 🛠 Чем теперь можно работать, не трогая прод

- `python scripts/agent-loop/orchestrator.py` — автоматический ограниченный
  Claude→Codex review-loop поверх локального mailbox. Официальные headless CLI
  авторизованы; Claude реализует, Codex проверяет в read-only sandbox, затем
  задача возвращается owner. Лимит раундов, lock, structured output и owner-gate
  включены; commit/merge/push/deploy/restart/prod запрещены. Полный smoke-test
  `SL-AUTO-SMOKE-1` 28.07 прошёл Claude → Codex → owner со статусом `ready`.
  Ручной GUI-режим через `mailbox.py` сохранён как fallback.
- `scripts/agent-loop/start-chat.cmd` — локальный Agent Room на
  `127.0.0.1:8765`: постановка задач, история диалогов Claude/Codex, живой
  статус, выбор моделей, реальные Codex rate-limit окна, evidence и финальный
  owner-report без терминала. Наружу не публикуется; несколько задач
  выстраиваются в локальную очередь. Reviewer PATH включает общий bundled
  Python, поэтому Codex выполняет проверки в read-only sandbox, а отсутствие
  необязательного CodeGraph больше не считается дефектом задачи.
- `python scripts/local-setup.py` — поднимает полную копию расширения на ПК с
  базой из вчерашнего бэкапа. Настоящие зрители и цены, Twitch не участвует.
- `python scripts/fake-mod.py --channel <id> --token <t>` — программа, которая
  притворяется игровым модом. Умеет то, чего игра по заказу не сделает:
  отказаться от команды, исчезнуть на середине, подтвердить дважды.
  Нужна потому, что в RimWorld никто не играет и проверять его иначе некому.
- `python scripts/verify-backup.py` — доказывает, что бэкап восстановим
  (запускается сам после каждого забора).

## 💸 Про лимиты (2026-07-24)

Владелец упирается в лимиты Pro. Главный пожиратель — **длинные сессии**:
прочитанные файлы/декомпили остаются в контексте и пересылаются на каждом шаге.
Отсюда правила: **новый чат чаще** (эта витрина для того и нужна — одно
сообщение вместо двухдневного хвоста), **одна сессия = один тип работы**,
**разведку — субагентам** (файлы оседают в их контексте, ко мне идёт выжимка),
рутину — на модель полегче. Механику вроде шаблонного кода можно отдавать
другому инструменту с отдельным лимитом; сложное расследование (лог+БД+декомпиль)
— держать здесь.
