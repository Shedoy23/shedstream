# Release record — какой ZIP чем был

Регламент выпуска требует: «каждый загруженный и каждый Released ZIP сохранять
неизменяемым с номером, датой, commit SHA и контрольной суммой SHA-256»
(`TWITCH_UPDATE_RELEASE_PLAYBOOK.md`, этап D). Файла под эту запись до 01.08 не
существовало — правило жило в регламенте и не исполнялось ничем.

**Зачем это нужно на практике, а не для порядка.** Без записи вопрос «сломает ли
правка бэкенда тот фронт, который сейчас у зрителей» решается реконструкцией по
датам коммитов вместо сверки с тем, что реально отдаёт CDN. Один раз это уже
стоило нам ответа: 01.08 нельзя было подтвердить, что магазин RimWorld сломан у
зрителей, — подтвердил владелец по памяти, а не архив.

**Проверено при сборке (не на слово скрипту):**
- в архиве нет `.env`, `.db`, `.py`, source maps, секретов и токенов;
- `overlay.html` НЕ входит — это виджет для OBS, а не Twitch video-overlay
  (правило: регламент, пункт 4-тер; упаковщик клал его до 01.08 вопреки правилу);
- строка версии `<meta name="shedlink-version" content="0.0.2">` стоит в обоих
  шеллах;
- все 22 файла архива побайтово совпадают с деревом коммита `1a05031`
  (html — с точностью до вставленной строки версии).

**Заметка о воспроизводимости:** побайтово пересобрать этот же ZIP нельзя —
файл `VERSION` содержит время сборки с точностью до минуты, и хеш меняется.
Сверять надо не хеш пересборки, а содержимое против commit SHA, как выше.

**Что в этой версии для зрителя** — `CHANGELOG_0.0.2.md`. Коротко: магазин
RimWorld оживает (у зрителей сломана бо́льшая часть, подтверждено владельцем),
причины отказа доходят текстом, цены на кнопках настоящие, четыре необратимых
действия спрашивают подтверждение.

⚠️ **Сборка ≠ готовность к подаче.** Собранный и проверенный ZIP закрывает
ровно этап D регламента — и ничего больше. На 02.08 **не начаты этапы C
(Local Test), E (Hosted Test на самом CDN-артефакте) и F (независимый аудит
версии + diff к Released)**, а трек B проверен только на деньгах: эффекты в
игре не смотрел никто. Полный список — `STATUS.md`, раздел «Поправка 02.08».

**Почему эта строка здесь:** 01.08 наличие готового архива было прочитано как
«осталось только поиграть». Архив — это один этап из девяти, и запись о сборке
не должна создавать впечатление финиша.
