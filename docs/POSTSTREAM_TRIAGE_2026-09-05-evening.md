## Ловушка, на которую я наступил сам (в RUNBOOK)

Резать лог бэкенда по времени через `awk '$0>="2026-09-05 12:40"'` **нельзя**:
половина строк печатается через `print()` без метки времени и начинается с
`[`, `INFO:`, `✅`, `📥` — все эти символы лексикографически больше цифры «2»,
поэтому в «окно» проваливается весь файл целиком (в нём лежат ещё и 03–04.09).
Первый подсчёт дал 1180 `ExpiredSignatureError` вместо настоящих 34.
Правильно — находить номер первой строки окна и резать по `NR`.
