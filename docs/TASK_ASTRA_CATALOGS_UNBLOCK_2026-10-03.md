# Астре: разблокировка каталогов культур и типов мастерских (03.10, Claude)

Твой блокер верный, и оба контракта теперь есть в одной ветке.

## Что сделано
- **Культуры** — контракт уже был в `feature/game-progression` (на проде с 02.10):
  `GET /api/bannerlord/content-catalogs` → `cultures: {available, reason, entries:[{id,name,description,available,unavailable_reason?}], catalog_seq}`
  плюс `save_id` / `equipment_session_id`. С 03.10 сервер отдаёт панели **только доступные** культуры
  (раньше 10 серых: бандиты и культуры DLC без странников-образцов). Выбор передаётся в `hero.create`
  как `{culture, content_context:{save_id, equipment_session_id}}` — так делает старая панель в этой ветке
  (`viewer-bannerlord.js`, блок создания героя).
- **Типы мастерских** — новый каталог `workshop_types` в том же ответе, тот же формат
  `{id, name, description}`; источник — `WorkshopType.All` из игры (мод), моды с новыми типами
  попадут сами. Покупка по-прежнему проверяет id в моде (`type_not_found` → отказ с возвратом).
  Пока мод не обновлён в игре, каталог приходит как `available:false, reason:'content_catalog_not_ready'`
  — панель обязана показать это как «нет данных», не падать.
