# Twitch Compliance — живые механики (ROADMAP 1.5)

**Правила получены:** 2026-06-11 — Twitch Extensions Guidelines & Policies
(`dev.twitch.tv/docs/extensions/guidelines-and-policies`). Не юридическое
заключение — инженерная проверка против опубликованных правил + риск ревью сабмита.

## Опорные правила
- **§5.2** — Extensions не могут позволять обменивать предметы на деньги/коммерцию.
- **§5.3** — лутбоксы со случайностью РАЗРЕШЕНЫ, если содержимое **не имеет денежной
  стоимости**. (Раскрытие шансов правилами НЕ требуется.)
- **§6.2.4** — запрет: **Bits** → лутбоксы со случайными неизвестными предметами.
- **§6.2.6** — запрет: **Bits** для «wagering/betting» на исходы вне контроля зрителя.
- **Нюанс:** §6.2.x сформулированы про **Bits**. Крустики — это внутренние очки
  расширения (за просмотр/чат), НЕ Bits. По букве §6.2.x не связывают крустики. НО:
  ревью сабмита консервативно к любой «гемблинг-форме», и сам проект уже удалял
  ставку из дуэлей ссылаясь на §6.2.6 — значит трактовка проекта осторожная.

По букве §6.2.x (Bits) не нарушает, но **высокий риск отклонения на ревью** + лексикон точно не проходит. |

## Итог
Из 6 проверенных механик **5 — ✅ COMPLIANT**. Единственный реальный риск перед
сабмитом — **ставки на турнир** (тот же wager-на-исход, что уже вырезали из дуэлей,
плюс запрещённые слова в UI). Это и нужно решить в 1.5.

Плюс попутно найден **UI-баг призов дуэлей** (фронт ≠ бэкенд) — не compliance, но
вводит зрителя в заблуждение, стоит поправить.

## Реализовано (2026-06-11) — решение владельца: вариант A

**Ставки на турнир → no-loss ПРОГНОЗ:**
- Backend (`routes/bannerlord.py`): `tournament.bet` теперь `price=0`, `amount=0` —
  крустики НЕ списываются. Убрана валидация min/max суммы.
- Backend (`modules/bannerlord/_adapter.py`): резолв заменён — верный прогноз
  (target == финальный winner) даёт фикс-бонус **500⦷** из платформенного пула;
  неверный — ноль (ничего не теряет). Убраны pot-split и burn. Aborted → прогнозы
  аннулируются (возвращать нечего).
- Frontend (`viewer.js`): убраны кнопки сумм (100/500/1000/5000); UI переписан —
  «🔮 Прогноз: победит @X?», «Угадай победителя — бесплатно, за верный прогноз бонус».
  Запрещённый лексикон («Ставка/Поставь/выигрыш/pot») удалён из живого UI (проверено grep).

**Баг призов дуэлей:** `duels.js` теперь показывает реальные выплаты 300k/200k/100k💎
(было stale 1M/500k/350k).

**Verify:** backend compile OK, frontend `node --check` OK, лексикон чист,
тесты **PASSED 1335 / FAILED 0**.

**Не задеплоено** на прод (нужен `deploy.ps1` после стрима). Прим.: `min_bet`/`max_bet`
ещё возвращаются из `/tournament-state` (фронт их игнорирует) — косметика, можно убрать позже.
