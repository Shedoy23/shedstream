## Откат

CLI не подключён к приложению: прекращение дальнейших запусков отключает очистку,
сервис перезапускать не нужно. Для возврата конкретного пакета событий после
проверки окончания эфира:

```sh
cd /root/twitch-extension/backend
../venv/bin/python event_archive.py restore --db viewers.db --archive /root/shedlink-deploy-backups/event-retention-20260927-0950/archives/НУЖНЫЙ-КАТАЛОГ
```

Повторить для нужных каталогов. Восстановятся только отсутствующие строки; конфликт
ID отменяет весь пакет. Новые события, покупки и балансы не откатываются.
Полную live SQLite старой копией не заменять. Сам restore на production не запускался:
он проверен на свежей server-копии перед удалением.

## Что осталось

Это **первый ручной проход**, автоматического расписания пока нет. Для регулярной
ретенции нужен запуск, который гарантирует копию вне сервера ДО каждого prune;
текущий операторский apply_batches.py делает именно это с ПК владельца.
Не запускать новый цикл со старым фиксированным as_of без подготовки нового релиза.
Старые module_actions не очищены: отдельно сохранить ключи повторов и поздние
возвраты. Архивы автоматически по сроку не удаляются.
