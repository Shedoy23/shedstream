    📦 Как подключить игру

    Один раз. Дальше мод подключается сам при каждом запуске игры.
    1. Скачать ShedLink Manager — приложение для Windows (версия {{ manager_version }}).
    2. Запустить и войти через Twitch. Кнопка в самом приложении, пароль оно не спрашивает и не видит.
    3. Выбрать игру и нажать «Установить». Manager сам найдёт папку игры, скачает мод, проверит подпись, положит его на место и пропишет твой токен. Руками ничего копировать не нужно.
    4. Запустить игру и нажать в Manager «Проверить готовность». Карточка вверху этой страницы покажет «Мод на связи» — обновлять не нужно.
    При первом запуске Windows покажет предупреждение SmartScreen: приложение пока не подписано сертификатом. Это ожидаемо — нажми «Подробнее» → «Выполнить в любом случае». Подпись появится позже.
    Поставить вручную, без Manager
    1. Взять мод. Напиши в телеграм, пришлю архив.
    2. Распаковать в папку модов игры:
      …\Mount & Blade II Bannerlord\Modules\Shedoy23.BannerlordLink\
    3. Включить мод в лаунчере игры, во вкладке «Модули».
    4. Положить рядом config.json:
      …\Modules\Shedoy23.BannerlordLink\config.json
    5. Запустить игру.
    В конфиге лежит твой токен — он равнозначен доступу к каналу в расширении. Не показывай его на стриме и не выкладывай никуда. Засветил — напиши, выпущу новый.
