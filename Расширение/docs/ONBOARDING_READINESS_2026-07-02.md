## Блокер 2 — установка мода + ПЛАН РАЗДАЧИ ЧЕРЕЗ shedoy23.ru
Мод — собранный вручную DLL/jar, готовой раздачи нет. **Решение (идея владельца):
поднять на пустующем `shedoy23.ru` витрину + скачивание модов.**

### Форма
- **Лендинг** `shedoy23.ru/` (сейчас пусто): что это, какие игры, «стать бета-стримером».
- **Скачивание** `/downloads/<game>/<version>/` — jar/dll + `install.md`.
- **Целостность/подпись:**
  - **SHA-256** рядом с каждым файлом (`<file>.sha256`) — стример/мод сверяет, не подменили ли.
  - Опц. **Authenticode code-sign** для .dll (~$100-400/год + cert) — снимает SmartScreen; для старта дорого, чекки+HTTPS дают 90%.
- **Config-by-code (будущее, снимает ручной json):** дашборд выдаёт короткий код,
  мод его «погашает» → сам тянет backend_url+token+channel_id. Убирает шаг 3-трение.

### ⚠️ Ограничения (сначала ограничения, потом код)
1. **SmartScreen / антивирус** на неподписанных .dll из веба → страшное «Windows
   protected your PC» / карантин. Многие стримеры сбегут. Митигация: code-sign
   (деньги) ИЛИ явная инструкция «это ожидаемо, More info → Run» + чек-сумма.
   **.jar (Minecraft) этим почти не страдает** — ещё довод начать с ShedColony.
2. **LGPL на Bannerlord.** Публичная РАЗДАЧА клин-рум-мода = выше видимость = выше
   шанс DMCA, чем приватное использование. Клин-рум закрыт (аудит 2026-06-11), но
   публичность поднимает ставку. → **Раздачу начинать с ShedColony (Minecraft):
   твой код, ноль лицензионных вопросов, .jar без SmartScreen, сервер уже живой.**
   Bannerlord/RimWorld — позже / через Steam Workshop.
3. **Репутация домена** — не хостить мусор рядом; чистая раздача.
4. **Twitch** — витрина для СТРИМЕРА (не для зрителя в расширении) → не нарушает
   extension-политику. Внешние ссылки запрещены только зрителю внутри расширения.

## Черновик install.md (ShedColony / Minecraft)
```
1. Скачай shedcolony-<ver>.jar отсюда: shedoy23.ru/downloads/minecraft/
2. Положи .jar в папку mods/ твоего сервера (или клиента) Minecraft 1.21.1 (NeoForge).
   Нужен также мод MineColonies (тех же версий).
3. Запусти сервер один раз — появится файл config/shedcolony.json.
4. Открой его и вставь два значения с дашборда (shedoy23.ru/streamer):
   "module_token": "<твой токен>",  "channel_id": <твой Twitch channel id>
5. Перезапусти сервер. Готово — зрители управляют колонистами из расширения.
```
