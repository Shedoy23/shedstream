# Задача Астре: что взять у конкурента BLT Refreshed (03.10)

## Зачем
Форк BLT от DarkTiger512 (`github.com/DarkTiger512/Bannerlord-Twitch`, «BLT Refreshed», релизы 5.5.x,
сентябрь 2026, Bannerlord 1.4.8) — самая живая ветка BLT, и у неё **своё расширение Twitch**
(панель зрителя, сервер `bltrefreshed.evepirate.nl`, 0.0.8 было на ревью Twitch 19.09). Это прямой
конкурент в нашей нише. Нужно понять, что у них есть такого, что зрителям интересно, а у нас нет,
и что из этого стоит сделать у нас.

## Главное правило: идеи — да, код — нет
BLT под LGPL. Читать README, заметки к релизам, документацию, смотреть описание механик — можно.
**Копировать код, тексты, картинки, конфиги — нельзя.** В отчёте — описание идеи своими словами и
наша версия, без кусков их кода. Их панель Twitch открывать как зритель можно, разбирать её бандл — нет.

## Что изучить
1. README, `docs/` (в т.ч. `docs/RELEASE-VARIANTS.md`), заметки ко всем релизам 4.12–5.5.5, страницу
   расширения/сервиса, если она публичная.
2. Составить **полный список механик**, сгруппировать: для зрителя в чате / в панели, для стримера,
   в кампании, в бою, события, экономика, оверлей, удобство настройки.
3. Отдельно — как они решили то, что у нас болело: изоляция каналов (несколько стримеров), возвраты
   денег при сбое игры, синхронизация после загрузки сейва, совместимость с крупными модами
   (у них отдельная сборка под TAOM — «The Old Realms»; владелец хочет, чтобы мы принимали такие
   моды без переписывания), конфигурация стримером без правки файлов.

## Как оценить каждую идею (таблица)
| Колонка | Что писать |
|---|---|
| Идея | одна строка своими словами |
| Есть ли у нас | нет / есть хуже / есть так же / есть лучше (ссылка на нашу механику) |
| Польза зрителю | что он делает и почему вернётся |
| Цена | грубо: часы, затронуто ли сервер/мод/панель, нужна ли новая версия на Twitch |
| Ограничения | правила Twitch (без азартной подачи — нам 24.08 отказали за неё; реальные деньги только через Bits), тонкий фронт (цены и тексты с сервера), содержимое игры из игры, изоляция каналов |
| Что заморозить взамен | по правилу проекта «фича входит — фича выходит»: какую нашу малоиспользуемую механику убрать |
| Вердикт | брать / брать позже / не брать — с причиной |

Не делать выводов «у нас этим не пользуются» по нулевым цифрам: пользователь у нас один канал
(правило проекта). Данные счётчиков нажатий с 03.10 можно приложить как сигнал, не как вердикт.

## Уже замеченные кандидаты (проверить и оценить, не ограничиваться ими)
- престиж кампании: сброс с выбором из 5 постоянных перков;
- бонус меньшей стороне боя (до 20%), чтобы зрители не скапливались на одной стороне;
- «цели стрима»: общий прогресс всего чата, награды участникам, оверлей;
- дуэли с таблицей лидеров (у нас свои дуэли — сравнить);
- найм свиты по классу героя;
- события: «проклятый артефакт», «бессмертный» босс, «крестовый поход»;
- живая карта кампании с героями зрителей (у нас есть `shedoy23.ru/map` — сравнить);
- конфигуратор стримера в браузере;
- исправление безопасности «HTML в именах» (у нас отдельная задача —
  `docs/TASK_ASTRA_XSS_AUDIT_2026-10-03.md`).

## Границы
Только чтение и анализ. Код не писать, ничего не публиковать, прод не трогать.

## Что сдать
1. Полный список их механик (своими словами).
2. Таблица оценки по колонкам выше.
3. Топ-5 «брать» в порядке пользы/цены, для каждой — спека на 5–10 строк для нашего проекта
   и что заморозить взамен.
4. Где они сильнее нас и где мы сильнее их (коротко, для позиционирования).
5. Что не удалось посмотреть и почему.
