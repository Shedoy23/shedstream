# Механические игры на кнопках — детальная проработка (ядро, компл. 3.5)

Owner ask (2026-08-26): НЕ викторина/знание — нужны МЕХАНИЧЕСКИЕ мини-игры,
управление КНОПКАМИ, исход решает навык. Заменяют кубики/дуэли ("быстрый 1v1
азарт") и делают ядро играбельным без игрового модуля. IDEAS ONLY — no code.

Общий принцип комплаенса (к каждой игре): исход определяет ЛОВКОСТЬ/ПАМЯТЬ/
ТАЙМИНГ/ЛОГИКА игрока, НЕ случайность-за-ценность, НЕ ставка, НЕ лутбокс. Призы
лиги — ТОЛЬКО статус (титул/значок), не валюта (правило Apple о конкурсах).
Честность (по Jim): у соперников ОДИН сид; тайминг считает СЕРВЕР; клиентскому
времени не верим. Гейт: спец + /twitch-compliance ДО кода.

---

## Хаб: «Аркадный клуб» ShedLink
Единый экран-хаб этих мини-игр. Каждая — набор кнопок в панели, играется 20–60с,
мгновенно понятна. Заменяет кубики/дуэли честным скиллом. Режимы у каждой:
СОЛО (личный рекорд), 1v1 (матчмейкинг, одинаковый сид → решает навык),
ЛИГА (бесплатный вход, сезон, приз = титул). 💎 капают за участие, тратятся
ТОЛЬКО на детерминированную косметику (рамки/значки) — никогда pay-to-win в лиге.

## 1. «Зелёный свет» — РЕФЛЕКС · S · FREE
- Панель: одна большая кнопка + статус.
- Раунд: кнопка красная «жди» → через 1–4с (анти-предугадывание) вспыхивает
  зелёным → жми максимально быстро. Тап до зелёного = фальстарт (переигровка).
  Замер в миллисекундах.
- Скилл-ось: чистый рефлекс.
- Режимы: соло best-ms; 1v1 — сервер шлёт «зелёный» обоим ОДНОВРЕМЕННО, быстрейший
  валидный тап побеждает; лига по среднему из N попыток.
- Комплаент: исход = скорость реакции (навык). Случайная задержка старта — это
  защита от пре-тайминга, НЕ награда-за-рандом; ценность не разыгрывается.
- Античит: время меряется на сервере (таймстамп «зелёного» ↔ приход тапа).
- ⚠ /twitch-compliance: подтвердить, что случайная задержка старта читается как
  анти-чит, а не как «случайный элемент». Формулировка: задержка не влияет на приз.

## 2. «Повтори сигнал» (Simon) — ПАМЯТЬ · S–M · FREE
- Панель: 4–6 цветных кнопок.
- Раунд: панель проигрывает последовательность вспышек (растёт на 1 каждый шаг),
  игрок повторяет тапами. Верно → длина +1; ошибка → конец. Счёт = длина.
- Скилл-ось: рабочая память + точность.
- Режимы: соло рекорд; 1v1 — обоим ОДНА последовательность (общий сид), кто
  дальше; лига по максимуму за сезон.
- Комплаент: последовательность фиксирована сидом, одинакова для всех → навык.

## 3. «Останови полосу» — ТАЙМИНГ/НЕРВ · S–M · FREE
- Панель: бегущий маркер по шкале + кнопка «Стоп». Зелёная зона в центре.
- Раунд: маркер снуёт всё быстрее; «Стоп» в зелёном → +раунд и зона СУЖАЕТСЯ;
  промах → конец. Счёт = пройдено раундов. (Джедайская жадность: дальше = уже.)
- Скилл-ось: тайминг + самоконтроль.
- Режимы: соло / 1v1 (одинаковая скорость и зоны по сиду) / лига.
- Комплаент: скорость/зоны детерминированы, исход = точность тапа.

## 4. «Взломай код» (Codebreaker/Mastermind) — ЛОГИКА · M · FREE
- Панель: палитра из 6 символов-кнопок + поле попыток + подсказки «на месте /
  не на месте».
- Раунд: скрытый код из 4 символов; собираешь догадку кнопками, получаешь
  фидбек, дедуктируешь за ≤N попыток. Это ЛОГИКА, не знание.
- Скилл-ось: дедукция.
- Режимы: 1v1 — обоим ОДИН код (сид), кто за меньше попыток/быстрее; соло за
  минимум попыток; лига.
- Комплаент: код фиксирован сидом, одинаков соперникам → дедукция, не угадайка;
  нет ставки. Лучший «дуэльный» формат — прямое 1v1 напряжение без азарта.

## 5. «Лови огонёк» (grid) — РЕФЛЕКС+ТОЧНОСТЬ · S–M · FREE
- Панель: сетка 3×3 или 4×4 кнопок.
- Раунд: загорается одна ячейка на короткое время; тап по ней = +очко, тап по
  тёмной/пропуск = штраф/ноль; темп растёт; 30 секунд.
- Скилл-ось: рефлекс + точность попадания.
- Режимы: соло score / 1v1 (одинаковая цепочка вспышек по сиду) / лига.
- Комплаент: цепочка вспышек детерминирована сидом; исход = сколько поймал.

## 6. «Запомни узор» (grid) — ЗРИТ. ПАМЯТЬ · S–M · FREE
- Панель: сетка 3×3/4×4.
- Раунд: ~1с подсвечен узор из K ячеек, гаснет, воспроизводишь тапами. Верно →
  K+1; ошибка → конец. Счёт = достигнутое K.
- Скилл-ось: зрительная память + точность.
- Режимы: соло / 1v1 (один узор по сиду) / лига.
- Комплаент: детерминировано, навык.

## Как это делает ядро самостоятельным
- Играбельно БЕЗ единого игрового модуля — чистое ядро, «что делать сейчас».
- 1v1-матчмейкинг сохраняет дуэльный азарт кубиков БЕЗ ставки (одинаковый сид).
- Свободная лига (ротация дисциплины по сезонам) = соревновательный крючок,
  приз статусный → ретеншн без денег/удачи.
- 💎-сток: только детерминированная косметика (рамки/значки клуба), не влияет на
  результат в лиге — честный скилл остаётся честным.

## Рекомендация к первому билду
- **«Зелёный свет» (S)** — мгновенно понятно, идеальный 1v1, минимум UI.
- **«Повтори сигнал» (S–M)** — другая ось (память); уже мини-клуб из 2 игр.
- Сильный третий — **«Взломай код» (M)**: логическая дуэль, самый «умный» азарт.
Два-три разных скилл-класса = клуб ощущается разнообразным сразу.
