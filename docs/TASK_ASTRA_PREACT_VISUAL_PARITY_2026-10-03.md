## Часть 1 — визуальный паритет (обязательна)
- Источник вида — старая панель: `Расширение/frontend/viewer.css`, разметка в `viewer*.js`, оболочки
  `extension.html`/`mobile.html`. Переносить стили и структуру блоков (не скрипты): шапка (аватар, ник, роль,
  TS/BS, баланс, доход/мин, полоса уровня), верхние вкладки, игровые подвкладки, карточки разделов с иконкой и
  раскрытием, цветовая семантика (золото — заголовки, зелёный — статусы/доход, красный — опасные действия,
  фиолетовый — основное), таблицы клана/королевства/семьи/вассалов, бейджи.
- Стартовая вкладка — игра (Bannerlord / активная игра канала), а не «Сообщество».
- Проверка: **скриншоты пара «старая | новая»** на 1280 и 375 px для каждого раздела, на одних фикстурах;
  в отчёте — таблица разделов с отметкой «вид совпадает / отличается и почему». Тесты паритета запросов
  должны остаться зелёными (вид меняется, трафик — нет).
- Вес: первая загрузка по-прежнему ≤ 150 КБ gzip; стили разделов — с их ленивыми чанками.

## Часть 2 — компоновка по счётчикам (после части 1, отдельными коммитами)
Данные 03.10 (26 зрителей): ядро 20+ — бой, призыв, способности, «Вблизи», герой, династия, инвентарь;
середина — прокачка, турнир, снаряжение, стены/налёт, стойка, магазин снаряжения, приказы отряду; редкое 1–5 —
мастерские, караваны, феоды, дипломатия, законы, армия, вассалы, семья, смена пола; ноль — питомцы, кейсы,
гильдии, голосования, дуэли. Сделать: ядро открыто; редкое — сетка плиток «Управление» (иконка, название,
короткий статус и значок-счётчик **с сервера**: «2 доступны», «+840 в день», «Мир с тремя»), образец —
скриншот владельца в `DEFERRED.md` (запись «компоновка Preact-панели»). Общие разделы с нулём — вглубь,
не удалять. Сервер для статусов плиток — не менять; где статуса нет в ответах — плитка без статуса + пункт
в отчёт «нужно поле от сервера».

## Правила (как прежде)
Сервер, моды, старая панель — не менять. Паритет запросов — сохранить. `minify:false`, читаемые исходники,
без внешних скриптов. Тест, не виденный красным, не считается. Публикации нет: ZIP + отчёт.
