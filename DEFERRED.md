# Отложено сознательно

Живой журнал того, что мы решили **не делать сейчас** — с причиной и с тем, что
это разблокирует. Не бэклог «когда-нибудь»: сюда попадает только то, по чему было
принято решение отложить.

Зачем: без такого списка отложенное либо теряется, либо всплывает третий раз как
«а давай обсудим» — и обсуждается заново с нуля.

**Правило ведения:** решили отложить — строка сюда в ту же сессию. Сделали —
строка удаляется (история в гите). Раздел «Решено НЕ делать» не чистится: он
существует, чтобы не возвращаться к закрытым вопросам.

Последнее обновление: 2026-07-22.

## A. Ждёт одобрения Twitch (разморозка фронта)

Фронт заморожен на CDN: любая правка = новая версия + ревью, дни. Копим батчем.

- [ ] **Переименовать активку невидимости.** В `BNR_POWER_LABELS` ключ
  `retribution_toggle` подписан 🪖 «Стойкость» — это техническая заглушка, чтобы
  выпустить механику при замороженном фронте (новый `power_key` без ярлыка =
  кнопки у зрителя нет вообще). Заменить на 🌫 «Невидимость» + убрать оговорку
  про «Стойкость» из описания класса ассасина (миграция m94). БД и мод трогать
  не нужно. Детали: `Расширение/docs/SPEC_ASSASSIN_INVIS.md`.
- [ ] **Накопленные переименования** стоек, навыков и приказов (владелец просил
  по ходу). Собрать список до разморозки, чтобы вкатить одним заходом.
- [ ] **Ачивки: решить про награду.** Сейчас это картинка в свёрнутом меню, за
  которую ничего не дают. Если хотим, чтобы механика работала на вовлечение,
  нужна награда — но это UI, значит фронт. (Крустики исключены, см. раздел D.)
- [ ] **Тонкий фронт: балансовые числа с бэка** — цены/кулдауны/лимиты не
  дублировать во фронте. Подробности и список кандидатов: `ROADMAP.md` §5.
- [ ] **Каталог законов королевства — с игры, а не рукописный.** Сейчас список
  зашит массивом в `viewer-bannerlord.js` (~стр. 1428): **12 законов из 32,
  которые есть в движке**. Зрителям недоступны две трети (земельный/военный
  налог, дорожные пошлины, право охоты, госмонополии, сенат, магистраты,
  наследование феодов, порча монеты и др.). Сверка 2026-07-22: сломанных id
  нет, все 12 совпадают с `DefaultPolicies`, но проверка была ручная и разовая.
  Правильное решение: мод отдаёт `MBObjectManager.GetObjectTypeList<PolicyObject>()`
  (настоящие имена/описания, плюс политики из чужих модов) → бэк → фронт.
  Бэк-часть можно делать заранее, но отрисовка списка — фронт, поэтому ждёт.
  Дешёвый промежуточный шаг, доступный сейчас: проверка в `lint_consistency.py`,
  что каждый id из фронта существует в игре — ловит разъезд после патчей
  Bannerlord автоматически (иначе кнопка молча перестанет работать).

## B. Ждёт данных (лог `[CONTRIB]` + киллы по классам после стрима)

Счётчик убийств был сломан (чинено 2026-07-21, коммит `844e6ae`): за всю историю
1 килл на 26 игроков. **До первого стрима с фиксом любые цифры ниже — угадывание.**

- [ ] **Калибровка оплаты за вклад.** `KILL_POINTS` / `DAMAGE_PER_POINT` /
  `ABSORB_PER_POINT` / `LADDER_SCALE` в `KillRewardBehavior` выставлены на глаз.
  В конце каждого боя мод пишет `[CONTRIB итог]` по каждому зрителю — по этим
  строкам подогнать. Спека: `Расширение/docs/SPEC_BATTLE_PAYOUT.md`.
- [ ] **Хвост лестницы вех.** Вехи 60–150 дают 3.3 млн из 3.99 млн и достижимы
  практически только берсерком. Разрыв берсерк/лучник упал с 36× до 9×, но не до
  единицы. Сгладить хвост = **ослабить берсерка**, чего мы избегаем осознанно
  (11 зрителей из 18 на нём). Решать по фактическим цифрам, не по ощущению.
- [ ] **Убийца беден** — по симуляции ×1.5 против ×3.8 у стрелков: мало киллов,
  мало урона, мало поглощения. Возможно, его вклад надо считать иначе.
- [ ] **Конный лучник.** У класса 0 игроков, и мы (m95) сняли ему вампиризм
  19.5% — самый высокий в ростере. По роли правильно, но забирать сустейн у
  класса, который никто не берёт, спорно. Если так и останется пустым — дать
  что-то взамен.
- [ ] **Пороги ачивок протухли.** «Богач» = 500 тыс. при максимуме у игрока
  17.7 млн; «Опытный воин» = 10 уровень при том, что он есть у 26 из 26.
  Поднять под нынешнюю экономику — но по данным, а не на глаз.
- [ ] **Заморозка анти-топ фичи** по метрикам использования (`ROADMAP.md` 2.3):
  метрики собираются, самой заморозки не делали.

## D. Решено НЕ делать (не возвращаться)

- **Ослаблять берсерка.** Срезать ему пробитие брони или рассечение = нерф
  любимого класса у большинства аудитории. Перекос чиним, поднимая остальных.
  (2026-07-21)
- **Крустики за ачивки и за бой.** Решение владельца: боевые награды только
  внутриигровые (динары + опыт). Заодно снимает вопросы к правилам Twitch —
  они про платформенные очки. (2026-07-21)
- **Штрафовать деньгами за смерть в бою.** Зритель и так теряет серию; отбирать
  заработанное = отбить желание лезть в бой. (2026-07-21)
- **`MilitiaSallyOutFix` в публичный мод.** Патч отключён у нас же
  (`Prepare() => false`) после воспроизводимого нативного вылета и конфликтует с
  SiegeFix / ImprovedGarrisons / AutoDeploySiegeEngines. Выкладывать людям то,
  что мы сами выключили из-за крашей, нельзя. (2026-07-21)
- **Английский на превью Siege Sanity** («NO LEAVE FROM SIEGE» — грамматически
  неверно). Владелец: «не страшно». (2026-07-22)
- **Трогать `damage_reflect_pct`.** Пассивка живая в коде, но не выдана ни
  одному классу — мёртвый груз. Чужой dead code не удаляем, просто знаем.
  (2026-07-21)
