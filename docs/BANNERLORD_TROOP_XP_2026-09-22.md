# Как в игре качается отряд — и что из этого может автопилот

Разведка 22.09 по запросу владельца: «научить автопилот качать отряд, найти
варианты быстрой прокачки опыта бойцов». Ничего не реализовано — это карта
возможностей с цифрами из самой игры.

Всё ниже взято декомпиляцией `TaleWorlds.CampaignSystem.dll` 1.4.8
(`DefaultPartyTrainingModel`, `DefaultCombatXpModel`), а не из памяти и не с
вики.

## 1. Источников опыта у бойцов ровно два

### Бой

```csharp
// DefaultCombatXpModel.GetXpFromHit
float num5 = 0.4f * attackerPower * targetPower * (damage + (isFatal ? targetMaxHP : 0));
num5 *= GetXpfMultiplierForMissionType(missionType);
```

Три вывода, каждый меняет тактику:

1. **Опыт пропорционален силе ЦЕЛИ.** Один удар по ветерану стоит кратно
   больше, чем по разбойнику. Фарм лутеров — худший из способов качать отряд,
   хотя кажется самым безопасным.
2. **Добивание дорого стоит.** Смертельный удар добавляет в формулу полный запас
   здоровья цели сверх урона. То есть важно, чтобы последний удар наносили ТВОИ
   бойцы, а не герой-стример в одиночку.
3. **Множитель за тип боя:**

   | тип | множитель |
   |---|---|
   | обычный бой | 1.0 |
   | **авторасчёт (симуляция)** | **0.9** |
   | турнир | 0.33 |
   | тренировочный бой на арене | 0.0625 |

   Авторасчёт стоит всего 10% потери опыта. **Это главная находка для
   автопилота:** он может молотить бои без стримера почти без штрафа. Арена для
   бойцов бесполезна — там и множитель 1/16, и участвует только герой.

### Суточный тик

```csharp
// DefaultPartyTrainingModel.GetEffectiveDailyExperience
if (mobileParty.IsLordParty && !troop.Character.IsHero && ...
    && (mobileParty.Party.Owner == null || mobileParty.Party.Owner.Clan != Clan.PlayerClan))
{
    stat.Add(15f + troop.Character.Tier * 3f);   // ← мимо игрока
}
```

**У отряда игрока базового суточного опыта НЕТ вообще** — эта ветка явно
исключает клан игрока. Весь суточный опыт у нас идёт только от перков:

| перк | кому даёт | условие |
|---|---|---|
| `Leadership.CombatTips` | всем | не в море |
| `Leadership.RaiseTheMeek` | тир < 3 | не в море |
| `Steward.DrillSergant` | всем | не в море |
| `Steward.SevenVeterans` | тир ≥ 4 | не в море |
| `OneHanded.MilitaryTradition` | пехоте | не в море |
| `Polearm.Drills` | всем | вторичная роль засчитывается |
| `Bow.Trainer`, `Crossbow.RenownMarksmen` | стрелкам | |
| `Throwing.Saddlebags` | пехоте | вторичная роль |
| `Athletics.WalkItOff` | пешим | **пока отряд ИДЁТ** |
| `Athletics.AGoodDaysRest` | пешим | **пока отряд СТОИТ в поселении** |
| `Scouting.ForcedMarch` | всем | идёт И мораль > 75 |
| `Scouting.Unburdened` | всем | идёт И перегружен |
| `Bow.BullsEye` (губернатор) | гарнизону | только гарнизон города |

Половина из них помечена `checkSecondaryRole: true` — **их достаточно иметь у
КОМПАНЬОНА в роли** (разведчик, квартирмейстер, инженер, лекарь), а не у самого
стримера. Это рычаг, который можно тянуть без перераспределения очков героя.

## 2. Что из этого может делать автопилот

По убыванию отдачи.

1. **Выбирать цель по силе, а не по безопасности.** Сейчас «побить лутеров» —
   это почти ноль опыта. Правильный критерий — самый сильный противник, которого
   отряд уверенно берёт: опыт растёт линейно по силе цели. Нужна оценка силы
   сторон (`MilitaryPowerModel.GetTroopPower` — та же функция, что в формуле
   опыта) и порог соотношения.
2. **Молотить бои авторасчётом.** 0.9 против 1.0 — почти даром, зато без
   стримера и без времени на миссию. Цена: в симуляции гибнет больше своих, чем
   в отыгранном бою, и `Leadership.TrustedCommander` работает ИМЕННО на
   симуляции (`CalculateXpGainFromBattles` проверяет `IsPlayerSimulation`).
3. **Держать условия суточных перков.** Дёшево и постоянно: не стоять без дела
   на карте (`WalkItOff`, `ForcedMarch` при морали > 75) либо наоборот
   отстаиваться в поселении (`AGoodDaysRest`), следить за моралью. Автопилот и
   так водит отряд — это вопрос выбора между «ждать на месте» и «ждать в
   движении».
4. **Гарнизон с губернатором-лучником.** Бойцы, оставленные в городе, качаются
   от `Bow.BullsEye` губернатора. Подходит для «второго эшелона», который сейчас
   просто стоит.
5. **Не давать герою добивать всех в одиночку.** Бонус за смертельный удар идёт
   тому, кто его нанёс. Если стример выкашивает поле сам, отряд не качается.

## 3. Чего делать НЕ стоит

- **Арена и турниры** для отряда бесполезны: множители 0.0625 и 0.33, и в обоих
  случаях дерётся только герой.
- **Начислять опыт напрямую через API** (`MemberRoster.AddXpToTroop`) — это уже
  не «научить автопилот играть», а выдать читы. Отдельный разговор с владельцем,
  и точно не под видом автопилота.
- **Фарм лутеров ради количества боёв** — против формулы: их сила в множителе
  почти ноль.

## 4. Что надо померить до реализации

Числа выше — из кода, а не из прогона. Прежде чем строить цикл прокачки:

- сколько реально даёт один авторасчётный бой против отряда разбойников тира 3–4
  по сравнению с боем против лордовой партии — замерить `XpGained` до и после;
- сколько своих бойцов теряется в симуляции против отыгранного боя (цена
  авторасчёта считается в рекрутах, а не только в опыте);
- какие из перечисленных перков вообще есть у стримера и у компаньонов в ролях —
  половина таблицы может быть недоступна, и тогда суточный источник почти пуст.

Без этих трёх чисел любой «цикл прокачки» будет настроен наугад.

## 5. Не забирать добычу → отдать её в опыт отряда (владелец был прав)

Такая механика в ваниль есть, и это **самый быстрый источник опыта бойцов из
всех найденных**. Реализация — `DefaultItemDiscardModel`, применяется **только
в экране добычи после боя** (`InventoryMode.Loot`).

### Как работает

Опыт начисляется за то, что ты **НЕ забрал** из левой (трофейной) половины
экрана. Берёшь предмет себе — его опыт тут же вычитается обратно
(`HandleDonationOnTransferItem`, знак меняется при переносе).

### Сколько именно

`GetXpBonusForDiscardingItem` — за каждую единицу предмета:

| тир предмета | опыт за штуку |
|---|---|
| Tier 1 | 75 |
| Tier 2 | 150 |
| Tier 3 | 250 |
| Tier 4–6 | 300 |
| без тира | 35 |

Умножается на количество. Для сравнения: суточные перки дают бойцу 2–20 опыта
в день. Один оставленный комплект брони тира 4 — это 300, то есть месяц
суточного тика.

### Что требуется

`PlayerCanDonateItem` проверяет перки раздельно:

| что оставляем | нужен перк | роль |
|---|---|---|
| оружие | `Steward.GivingHands` (Steward, тир 5) | отряд |
| броня | `Steward.PaidInPromise` (Steward, тир 4) | **засчитывается от КОМПАНЬОНА в роли интенданта** |

То есть броню можно конвертировать, не трогая перки стримера — достаточно
посадить компаньона с нужным перком интендантом. Оружие — нет, тут нужен перк
у самого отряда.

Без перка опыт за оставленное равен нулю: добыча просто пропадает.

### Потолок

`_donationMaxShareableXp = MobilePartyHelper.GetMaximumXpAmountPartyCanGet(party)`
— сумма по всем стекам того, **сколько каждому не хватает до следующего
апгрейда** (`upgradeXpCost × количество − накопленный опыт`). Опыт сверх потолка
пропадает, в экране это подписано отдельно.

Следствия:
- переливать добычу в опыт имеет смысл, когда в отряде много НЕДОкачанных
  бойцов: потолок растёт вместе с их числом;
- отряд из максимально прокачанных бойцов не примет ничего — потолок будет ноль,
  и вся оставленная добыча сгорит впустую;
- значит порядок такой: сначала набрать рекрутов, потом сливать в них добычу.

### Что делать автопилоту

Идея владельца формулируется прямо: **если денег больше порога — добычу не
забираем, она уходит в опыт.** Конкретно:

1. В `BannerlordAutopilot/src/AutopilotLoot.cs` уже есть работа с экраном добычи
   (`PollLootScreen`). Туда добавляется правило: при `Hero.MainHero.Gold >
   порога` (владелец назвал 1 000 000) не перетаскивать трофеи к себе.
2. Правило должно быть УМНЕЕ, чем «не брать ничего»: забирать всё равно стоит
   лошадей и припасы (они не дают опыта, а нужны отряду), а оставлять — оружие и
   броню, за которые опыт как раз и платят.
3. Обязательно смотреть на потолок: если `GetMaximumXpAmountPartyCanGet` уже
   ноль, добычу надо ЗАБИРАТЬ и продавать, иначе она сгорает зря.
4. Проверить наличие перков перед тем, как что-то оставлять: без
   `GivingHands`/`PaidInPromise` это просто выброшенные деньги.

### Чего не проверял

Живого прогона не делал: все числа — из кода 1.4.8, не из игры. До реализации
стоит один раз открыть экран добычи после боя и сверить подпись «получено
опыта» с расчётом по таблице выше — это дешевле, чем отлаживать автопилот по
жалобам.
