# Bannerlord: настройки интерфейса без нового Twitch ZIP

Клиент содержит четыре заранее проверенных секции «Боя»: `summon`,
`active_powers`, `tournament`, `weapon_choice`. Бэкенд отдаёт их порядок,
видимость, подписи и три цвета каждого тира в поле `ui` существующего
`GET /api/bannerlord/config`. При недоступности бэкенда фронт оставляет
встроенный порядок и цвета. Никакой HTML, JS, CSS или новый тип действия
из ответа сервера не исполняется.

Рабочий файл на сервере: `/root/twitch-extension/data/bannerlord_ui_config.json`.
Для локальной разработки: `Расширение/data/bannerlord_ui_config.json`.
Путь можно изменить переменной окружения `BANNERLORD_UI_CONFIG_PATH`.
Файл находится **вне** каталогов `backend` и `frontend`, которые обновляет
`deploy.ps1`; его не затронет следующая публикация. Бэкенд перечитывает
файл на каждый запрос, а зритель получит обновление при перезагрузке панели.
Отсутствующий, повреждённый или слишком большой файл приводит к безопасным
встроенным значениям. Изменять файл следует атомарно: подготовить новый
JSON рядом и переименовать после проверки, сохранив предыдущую копию.

Пример настройки:

```json
{
  "version": 1,
  "combat_order": ["summon", "active_powers", "tournament", "weapon_choice"],
  "combat_visible": {
    "summon": true,
    "active_powers": true,
    "tournament": true,
    "weapon_choice": true
  },
  "labels": {
    "active_powers": "Активки",
    "tournament": "🏆 Турнир зрителей",
    "weapon_choice": "Оружейная способность",
    "summon_ally": "📯 Призвать за стримера",
    "summon_enemy": "⚔️ Призвать против стримера",
    "discard": "🗑 Выкинуть вещь"
  },
  "tier_colors": {
    "1": {"text": "#c0c3ca", "border": "#5b5e66", "background": "#2b2d31"},
    "2": {"text": "#89dba1", "border": "#467457", "background": "#203127"},
    "3": {"text": "#87c6fa", "border": "#426c91", "background": "#202d3a"},
    "4": {"text": "#c7a0f5", "border": "#785398", "background": "#30253b"},
    "5": {"text": "#f2b17f", "border": "#966139", "background": "#3b2b20"},
    "6": {"text": "#f5d174", "border": "#aa8436", "background": "#39311e"}
  }
}
```

Поля можно задавать частично. `combat_order` принимается только как полный
список четырёх разных известных секций; остальные поля отвергаются по
отдельности, если не проходят тип/формат. Цвет — строго `#RRGGBB`, подпись —
печатная строка до 64 символов. Управление ценами, разрешениями и списанием
денег здесь отсутствует: это правила бэкенда и мода.

Эта схема позволяет менять оформление **уже предусмотренных** элементов.
Новая механика, кнопка или внешний скрипт требуют нового ZIP и обычного
цикла Twitch Review. Сверять настройки надо на Hosted Test точного ZIP,
который планируется отправить на Review.
