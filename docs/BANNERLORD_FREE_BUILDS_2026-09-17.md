# Bannerlord: свободная сборка для новой кампании

Владелец одобрил реализацию 17.09.2026 и явно отменил перенос существующих
героев: новая игра будет начата с новой системой. Старые сейвы/герои не
обнуляются и не преобразуются. Frontend разрешено менять, Review не отправлен.

## Принятая схема

1. Новый герой получает признак build.version=1 в сейве. Выбор экипировки
   свободный через магазин/инвентарь первого этапа; уровни тиров без изменений.
2. Одна специализация: guardian («Защитник», +15% HP), assault («Натиск»,
   +10% ближнего урона), marksman («Стрелок», +10% дальнего урона), mobility
   («Подвижность», +10% скорости пешком). Это стартовые значения для проверки
   баланса. Специализация не выдаёт вещи и не меняет навыки или формацию.
3. Одна выбранная оружейная активка, выбирается между боями из доступных
   надетому комплекту. Одноручное — rage; двуручное — cleave; древковое —
   shield_break_burst; лук/арбалет — explosive_arrows; метательное — poison_dot;
   щит — ironskin_toggle. Общее лечение остаётся отдельным действием.
4. Сила оружейной активки зависит от профильного навыка: ранги 1/2/3 при
   значениях ниже 50 / от 50 / от 150. Уровень героя открывает магазин.
5. Для оружейных активок общая перезарядка 90 секунд. Смена выбора, экипировки,
   специализации или загрузка сейва не обнуляет сохранённую отметку кулдауна.
   Мод проверяет реальное оружие перед применением и условия боевого эффекта.
6. Три стартовых набора: одноручное+щит, двуручное, лук+стрелы. Конкретные
   предметы установленной сборки показаны до получения, без случайности.
   Один бесплатный набор на героя; при отсутствии совместимых базовых вещей
   набор недоступен с причиной. Замены вещей не уничтожают прежний инвентарь.
7. Вкладка «Герой»: специализация и стартовый набор. «Инвентарь»: вещи.
   «Бой»: выбор одной оружейной способности, сила/навык/цена/кулдаун и активация.
8. Мод владеет состоянием сборки в сейве. Backend хранит зеркало в том же
   упорядоченном inventory snapshot, с проверкой save/hero/session/sequence.
   Новые действия и paid power.activate проверяются сервером и модом;
   старые классовые бонусы не складываются с новыми у build.version=1.

## Ограничения и контракт

Проверка платформы первого этапа сохраняется: нет случайной платной выдачи,
денежной торговли, Bits или обмена предметами. Новые настройки/старт бесплатны;
цены действующих активок берутся из существующей серверной таблицы.
[Twitch Extensions §2, §3, §5](https://dev.twitch.tv/docs/extensions/guidelines-and-policies/).
Самостоятельная реализация на существующих эффектах ShedLink и API игры,
исходники BLT не копируются. Снятая механика — классовая выдача/ограничения и
классовые бонусы для новых героев; отдельная параллельная система не добавляется.

GET `/api/bannerlord/build`: готовность, причины блокировки и `build`.
Действия: `hero.set_specialization {specialization}`,
`hero.select_weapon_power {weapon_type}`, `hero.claim_starter {starter_kit}`.
Зритель не задаёт получателя, силу, ранги, цены и содержимое набора.

## Состояние проверки

Реализация в работе. Production, ZIP и DLL в игре не изменены.
Живые бой/создание/сохранение/загрузка — не проверено.
