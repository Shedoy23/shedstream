# SPEC — Классы v2: 12 → 6 базовых, различимых не только названием

**Статус:** спека на «ок» владельца, не реализовано. Создано 2026-07-20.
**Продолжает:** `CLASS_OVERHAUL_PLAN.md` (Фаза 1, m80, задеплоена) — фактически это её Фазы 2+3,
пересобранные под решение владельца «6 базовых классов».
**Решения владельца (зафиксированы):** состав 6; кавалерист = `knight`; **броня у всех**
(различия — параметры/характеристики/способности); стиль брони — культурные скины;
тиры брони — свои квантильные (движковые лгут для лёгких классов).

---

## 1. Цель

6 классов, каждый читается **с одного кадра стрима** (силуэт+палитра) и **ощущается** иначе
(параметры, скилл, силы, команды отряда). Меньше каталог → меньше поддержки, выше плотность
выбора (сейчас 19 зрителей на 12 классов, половина — berserk).

## 3. Броня

### 3.1 Броня у всех
Убрать `SkipArmorSlots` у `berserk` (сейчас без шлема и нагрудника) — единственный класс с голым
телом. Живучесть «стеклянной пушки» держат **числа** (hp_mult/dmg_reduction), не отсутствие брони.
Описание в каталоге переписать (сейчас «голый торс»).

### 3.2 Культурный фильтр (стиль)
`ClassLoadout.Config` += `string CultureId`. В `FindTieredItem` для armor-слотов: фильтр
`item.Culture?.StringId == CultureId` **с фолбэком** (пусто → отпустить культуру, материал
остаётся) — паттерн фолбэков в пикере уже есть. Оружие/лошади культурой НЕ фильтруем.

### 3.3 Свои квантильные тиры брони (вместо движковых)
**Факт (данные игры + формула `DefaultItemValueModel.CalculateArmorTier`):** движковый тир =
очки брони → лёгкая броня физически кэпится на T1–T3 → зритель-берсерк УЖЕ СЕГОДНЯ платит за
gear_tier 4→6 и получает ту же кожанку (латентный «платный no-op» на броне).
**Решение:** для armor-слотов тир НЕ движковый: пул (культура+материал) ранжируем по движковой
же формуле очков (1.2×head + body + leg + arm, слот-множители Leg×1.6/Hand×1.7/Head×1.2/Cape×1.8)
и режем на **6 квантильных ступеней** = наши T1..T6. Каждый класс получает 6 РЕАЛЬНЫХ шагов
«обноски → лучший доспех своей культуры», апгрейд всегда виден глазами.
- Тонкие пулы (покрытие из данных): Асераи Medium ноги/руки = **0 предметов**; плащи/руки у
  многих культур 1–4 шт. Фолбэк тонкого слота: тот же материал, любая культура (слоты
  малозаметны, силуэт делают тело+голова+плащ). Пул из N<6 → соседние ступени делят предмет (ок).
- Оружие: движковые тиры как есть (там прогрессия честная).
- Бонус-полировка: внутри ступени предпочитать `item.Appearance` повыше (красивое, не рандом).

## 8. Порядок работ и деплой

1) **Мод (C#, `ClassLoadout.cs`)**: культурный фильтр + квантильные armor-тиры + убрать
   SkipArmorSlots берсерка + `Classes` оставить 12 ключей (депрекейт — бэкенд-гейт; мод должен
   уметь одеть и старый ключ до миграции игрока).
2) **Миграция** каталога/powers/remap + регистрация в `run_migrations()` (lint это гейтит).
3) **Фронт**: гейты §6 + пикер классов (6 карточек, описания стилей).
4) Деплой: бэк+фронт вместе (каталог и карточки согласованы), DLL — при закрытой игре.
   Фронт сейчас ЗАМОРОЖЕН на Twitch-ревью → фронт-часть после вердикта ЛИБО в след. версию
   (не блокирует бэк/мод: старый фронт покажет 6 активных классов из /catalog автоматически,
   гейты команд отряда врут и сейчас).
5) **In-game verify чек-лист:** каждый из 6 — set_class → выглядит культурно-когерентно;
   апгрейд тира брони меняет вид на КАЖДОМ шаге (особенно берсерк/лучник T4→6); берсерк в
   шлеме и нагрудниках; мигрированный (assassin) получил berserk + тост; гейты Набег/
   Перестрелка/конь — по новым спискам; активки по матрице §5 работают.
