# Запрет самостоятельной смены королевства зрителями

По запросу владельца запрещены решения дипломатического ИИ о вступлении,
выходе, измене и найме/уходе наёмником для клана с лидером-зрителем.
ViewerKingdomAiPatch перехватывает пять Consider-методов DiplomaticBartersBehavior.
Определение зрителя: существующий HeroNaming.IsAdopted(clan.Leader), не имя клана.
Ручные команды и сами ChangeKingdomAction не перехвачены; роспуск/поражение
королевства и прочие принудительные игровые события не блокируются.
Мир, война и обычные NPC-кланы сохраняют штатные решения.
Защита не заявляется для стороннего мода, который обходит эти методы напрямую.

Фронтенд не изменён по явному указанию владельца. Предупреждение правителю
о роспуске и привязка ручной команды выхода к ожидаемому kingdom_id не включены.
Уже уничтоженное королевство автоматически не восстанавливается.

Проверки: тест сначала красный (f2e5eff), затем 22/22 на настоящих Harmony-prefix
с тестовыми классами движка. Отдельно все пять методов реально установленного
TaleWorlds.CampaignSystem успешно найдены и пропатчены вне процесса игры.
Release: 0 ошибок/предупреждений. Реальный SaveManager save/load: 6/6.
Harness использует net472, как игра: установленный Harmony несовместим с
использованным динамическим IL API в net8, поэтому net8 для него не годится.
Существующий HeroStateSync.BuildSnapshotForMaster сохранён.
