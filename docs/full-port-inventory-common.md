# Common legacy action inventory for the Preact panel port

Scope: read-only comparison of `Расширение/frontend/{pets.js,pet-stage.js,cases.js,shop.js,guilds.js,voting.js,duels.js,tictactoe.js,tugofwar.js,viewer.js}` with `frontend-next/src/panel`. File:line references are relative to the repository root. “Gap” means the action has no equivalent in the current Bannerlord Preact panel source; it does not mean the backend route is missing.

## Port boundary

`frontend-next/src/panel/PanelApp.tsx:12-19,46-58` exposes identity, development, equipment, combat, and dynasty tabs, and starts only Bannerlord controllers. The individual Bannerlord views call Bannerlord Module/API contracts (for example `EquipmentView.tsx:83,131-146` and `CombatView.tsx:31-54`). None of the legacy modules below is imported or mounted there. These are separate products and contracts: old RimWorld/pet/case/guild/voting/social-game endpoints use viewer JWT plus crustics or their own game state; the Preact panel uses Bannerlord state, signed action policy, and gold quotes. Do not port the old catalog or price model into Bannerlord equipment.

## Shared stale-DOM / handoff risks

- Legacy modal helpers append to `#overlay-panel` when present, otherwise `document.body` (`pets.js:105`, `cases.js:86`, `viewer.js:1377,1407,1454,1513`). Preact panel is mounted under `#panel-root` (`frontend-next/src/panel/main.tsx:19`), with its own tabs and component-local handlers. Reusing the global legacy `data-action` delegation (`viewer.js:88-90,188-214`) against a Preact subtree can make stale/duplicate action attributes activate the old modal handler.
- Pet slots are especially schema-sensitive (see row above). Before extending item data, reconcile `pets.js:180-185`, `pets.js:423-435`, `pet-stage.js:98-103,151-161`, and backend catalog/equip validation; stale cached client JS can otherwise show an item with no visual layer or removal control.
- RimWorld shop had a real global-name collision: `shop.js:314-318` records that `_buyItem` was overwritten by `pets.js`, causing shop requests to hit `/api/pet/purchase`; the helper is now `_rwBuyItem`. Preserve distinct handler names and request endpoints when both classic scripts are present.
- None of the listed legacy actions are represented by a Preact view. `frontend-next/src/panel/PanelApp.tsx:12-19,46-58` currently mounts only Bannerlord panel tabs; similar-sounding Dynasty/Guild or Combat/Duel buttons are not parity.
