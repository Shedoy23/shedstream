## 📐 Categorization Legend

- 🟢 **BLT-DIRECT** — реальный port фичи из BLT/forks, поведение должно быть identical
- 🟡 **BLT-INSPIRED** — идея из BLT, наша реализация отличается (например, backend-mediated вместо in-game)

## 🛠 Verbose Logging — как включить

**Env var**: `set BANNERLORDLINK_VERBOSE=1` перед запуском Bannerlord (Windows cmd).

**Flag file**: создай пустой файл
`X:\SteamLibrary\steamapps\common\Mount & Blade II Bannerlord\Modules\Shedoy23.BannerlordLink\Configs\bannerlordlink_verbose.flag`

При запуске mod пишет в начало лога: `[VERBOSE] verbose logging = ON (детальные logs включены)`.

**Log file location**:
`Logs/Mods/BannerlordLink.{TIMESTAMP}.log` в documents folder Bannerlord.
